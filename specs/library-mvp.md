# Offline library milestone

The acceptance check starts with an empty application data directory and a stable private staging file. Import preserves the staged bytes and records the isolated reader's package metadata. Import the same bytes at another path, then change the bytes under a known path or package identifier. The first import should identify the existing book. The second should require an explicit decision. Edit the displayed title, save a version-specific position, restart, and recover the same IDs and values by moving the portable directory alone. Interrupt publication after SQLite commits and reopen to finish the same change exactly once. Check managed paths using synthetic metadata and symlink fixtures.

The desktop supplies stable staged input and owns format validation, folder selection and the user interface. See the [crate contract](../crates/ebook-library/README.md).
